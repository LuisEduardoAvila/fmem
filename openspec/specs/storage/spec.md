# Storage Specification

> Generated by spec-gen v1.0.0 on 2026-02-28

## Purpose

Manages SQLite database operations for document and chunk metadata storage

## Requirements

### Requirement: StoreDocument

The system SHALL shall store or update a document in the sqlite database

#### Scenario: Unnamedscenario
- **GIVEN** a document with path 'README.md' does not exist in the database
- **WHEN** store_document is called with path 'README.md', content '# Example\nContent', last_modified 1710000000, created_at 1710000000
- **THEN** document is inserted with id 1 and file_hash '5d41402abc4b2a76b9719d911017c592'

#### Scenario: Unnamedscenario
- **GIVEN** a document with path 'README.md' already exists in the database with id 5
- **WHEN** store_document is called with path 'README.md', content '# Updated', last_modified 1710001000, created_at 1710000000
- **THEN** document id 5 is updated with new content and last_modified 1710001000

### Requirement: GetDocument

The system SHALL shall retrieve a single document by its filepath

#### Scenario: Unnamedscenario
- **GIVEN** a document with path 'README.md' exists in the database with id 1
- **WHEN** get_document is called with path 'README.md'
- **THEN** returns dict containing id 1, filepath 'README.md', content, last_modified, created_at, file_hash

#### Scenario: Unnamedscenario
- **GIVEN** no document with path 'missing.md' exists in the database
- **WHEN** get_document is called with path 'missing.md'
- **THEN** returns None

### Requirement: GetAllDocuments

The system SHALL shall retrieve all documents from the database

#### Scenario: Unnamedscenario
- **GIVEN** documents with paths 'README.md' and 'guide.md' exist in the database
- **WHEN** get_all_documents is called
- **THEN** returns list containing two document dicts with filepath 'README.md' and 'guide.md'

#### Scenario: Unnamedscenario
- **GIVEN** the database is empty
- **WHEN** get_all_documents is called
- **THEN** returns empty list

### Requirement: DeleteDocument

The system SHALL shall delete a document and all its associated chunks from the database

#### Scenario: Unnamedscenario
- **GIVEN** a document with path 'README.md' exists with id 5 and has 3 chunks
- **WHEN** delete_document is called with path 'README.md'
- **THEN** document id 5, its embeddings, and 3 chunks are deleted and returns True

#### Scenario: Unnamedscenario
- **GIVEN** no document with path 'missing.md' exists
- **WHEN** delete_document is called with path 'missing.md'
- **THEN** returns False

### Requirement: StoreChunk

The system SHALL shall store or replace a chunk in the chunks table

#### Scenario: Unnamedscenario
- **GIVEN** no chunk with id 'chunk_1' exists
- **WHEN** store_chunk is called with chunk_id 'chunk_1', parent_file 'README.md', heading 'Introduction', content 'Some text', keywords ['intro'], category 'guide', token_count 10, chunk_index 0
- **THEN** chunk is inserted and returns True

#### Scenario: Unnamedscenario
- **GIVEN** a chunk with id 'chunk_1' already exists
- **WHEN** store_chunk is called with chunk_id 'chunk_1' and new content 'Updated text'
- **THEN** chunk is replaced with new content and returns True
