# Search Index Specification

> Generated by spec-gen v1.0.0 on 2026-02-28

## Purpose

Manages FAISS vector index operations and metadata mapping. Provides fast semantic similarity search using embeddings with persistent storage and lifecycle management.

## Requirements

### Requirement: AddEmbedding

The system SHALL add embeddings to FAISS index with metadata mapping

#### Scenario: AddChunkEmbedding
- **GIVEN** embedding vector shape (384,) for "chunk_1" from "file.md"
- **WHEN** add is called with chunk_id, filepath, heading, processed_content
- **THEN** embedding is reshaped to (1, 384) and added to FAISS IndexFlatIP
- **AND** metadata is stored in _chunk_index_map with filepath, chunk_id, heading, content
- **AND** returns FAISS index position (integer)

#### Scenario: AddBatch
- **GIVEN** already have 100 embeddings in index
- **WHEN** add 50 more embeddings
- **THEN** new embeddings start at index position 100
- **AND** _chunk_index_map is extended with 50 new entries

### Requirement: SearchEmbeddings

The system SHALL search FAISS index for similar embeddings

#### Scenario: BasicSimilaritySearch
- **GIVEN** 500 embeddings in index, query embedding vector
- **WHEN** search is called with top_k=10
- **THEN** returns FAISS index distances and indices for top 10 matches
- **AND** maps indices to chunk metadata via _chunk_index_map
- **AND** returns list of results with score, filepath, chunk_id, heading, content

#### Scenario: MinimumScoreThreshold
- **GIVEN** top_k=10 results with scores [0.95, 0.87, 0.45, 0.30, 0.15, ...]
- **WHEN** search is called with min_score=0.3
- **THEN** returns only results with score >= 0.3
- **AND** filters out result with score 0.15

#### Scenario: EmptyIndex
- **GIVEN** FAISS index has no embeddings (ntotal=0)
- **WHEN** search is called
- **THEN** returns empty list []

#### Scenario: DuplicateFiltering
- **GIVEN** multiple FAISS indices point to same (filepath, chunk_id)
- **WHEN** search returns these indices
- **THEN** filters out duplicates
- **AND** processes each unique chunk only once

### Requirement: DeleteChunks

The system SHALL remove all chunks associated with a file

#### Scenario: DeleteFileChunks
- **GIVEN** file "doc.md" has 5 chunks at indices [10, 11, 12, 13, 14]
- **WHEN** remove_chunks_by_filepath is called
- **THEN** rebuilds FAISS index without these 5 embeddings
- **AND** rebuilds _chunk_index_map without these entries
- **AND** returns number of chunks removed (5)

#### Scenario: NoMatchingChunks
- **GIVEN** file "nonexistent.md" not in index
- **WHEN** remove_chunks_by_filepath is called
- **THEN** returns 0 (nothing removed)

### Requirement: PersistIndex

The system SHALL save and load FAISS index and chunk mappings

#### Scenario: SaveIndexAndMapping
- **GIVEN** FAISS index with 1000 embeddings, _chunk_index_map populated
- **WHEN** save is called
- **THEN** writes faiss_index.fai with FAISS binary data
- **AND** writes chunk_index_map.json with metadata array
- **AND** returns True on success

#### Scenario: LoadExistingIndex
- **GIVEN** faiss_index.fai and chunk_index_map.json exist from previous run
- **WHEN** load is called
- **THEN** reads FAISS index into memory
- **AND** populates _chunk_index_map with 1000 entries
- **AND** returns True

#### Scenario: LoadMissingFiles
- **GIVEN** index files do not exist
- **WHEN** load is called
- **THEN** initializes new empty IndexFlatIP
- **AND** initializes empty _chunk_index_map
- **AND** returns False

### Requirement: GetChunkMapping

The system SHALL retrieve metadata for specific FAISS index

#### Scenario: GetValidMapping
- **GIVEN** FAISS index 42 exists in _chunk_index_map
- **WHEN** get_chunk_mapping is called with faiss_idx=42
- **THEN** returns {'filepath': 'x.md', 'chunk_id': 'ch1', 'heading': 'H1', ...}

#### Scenario: OutOfRangeIndex
- **GIVEN** FAISS index 999 is out of range (map has 100 entries)
- **WHEN** get_chunk_mapping is called
- **THEN** returns None

### Requirement: ResetIndex

The system SHALL clear all index data

#### Scenario: ClearAllData
- **GIVEN** FAISS index with 500 embeddings, _chunk_index_map with 500 entries
- **WHEN** reset is called
- **THEN** calls faiss.index.reset()
- **AND** clears _chunk_index_map to []
- **AND** returns nothing (void)

### Requirement: IndexLifecycle

The system SHALL report index state

#### Scenario: GetIndexCount
- **GIVEN** 500 embeddings in FAISS
- **WHEN** len(search_index) is called
- **THEN** returns 500

#### Scenario: GetIndexConfig
- **GIVEN** SearchIndex initialized with dimension=384, data_dir="~/.fmem"
- **WHEN** accessing attributes
- **THEN** dimension == 384, data_dir == expanded path

## Technical Notes

- **FAISS Index type**: IndexFlatIP (Inner Product) for cosine similarity with normalized vectors
- **Dimension**: 384 (all-minilm:22m embeddings)
- **Chunk mapping**: List of dicts: [{'filepath': str, 'chunk_id': str, 'heading': str, 'processed_content': str, 'original_length': int}, ...]
- **Persistence**: FAISS binary (.fai) + JSON mapping (.json)
- **Deletion strategy**: Rebuild entire index (FAISS doesn't support efficient individual deletion)

## File Locations

```
~/.openclaw/memory/index/
├── faiss_index.fai          # FAISS binary format
└── chunk_index_map.json     # JSON array of metadata
```
