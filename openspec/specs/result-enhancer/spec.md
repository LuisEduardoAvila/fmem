# Result Enhancer Specification

> Generated by spec-gen v1.0.0 on 2026-02-28

## Purpose

Enhances search results with recency and location-based ranking. Applies multi-factor scoring to combine semantic similarity with document age and file location importance.

## Requirements

### Requirement: EnhanceWithRecency

The system SHALL calculate recency scores based on file modification time

#### Scenario: RecentFileBoost
- **GIVEN** file modified 2 days ago, recency_threshold_days=30
- **WHEN** _calculate_recency_score is called
- **THEN** returns score ~0.93 (1.0 - 2/30)

#### Scenario: OldFileMinimumScore
- **GIVEN** file modified 60 days ago, threshold=30
- **WHEN** _calculate_recency_score is called
- **THEN** returns min_recency_score (0.2)

#### Scenario: AppendOnlyFileHandling
- **GIVEN** memory file "memory/2026-02-28.md" with recent mtime
- **WHEN** enhance is called
- **THEN** detects append-only file via _is_append_only_file
- **AND** reduces recency_weight to half (0.2 * 0.5 = 0.1)
- **AND** prevents old entries appearing more recent than they are

#### Scenario: AppendOnlyDetection
- **GIVEN** filepath "memory/2026-02-28.md" matches pattern with date
- **WHEN** _is_append_only_file is called
- **THEN** returns True

### Requirement: EnhanceWithLocation

The system SHALL calculate location weights based on file path

#### Scenario: HighImportanceLocation
- **GIVEN** filepath contains "docs/" or "decisions/"
- **WHEN** _calculate_location_weight is called
- **THEN** returns 1.5 for docs, 1.4 for decisions (boosted importance)

#### Scenario: MediumImportanceLocation
- **GIVEN** filepath contains "projects/", "work/", "active/"
- **WHEN** _calculate_location_weight is called
- **THEN** returns 1.3 for projects, 1.2 for work/active

#### Scenario: LowImportanceLocation
- **GIVEN** filepath contains "chats/", "conversations/"
- **WHEN** _calculate_location_weight is called
- **THEN** returns 0.8 (reduced importance)

#### Scenario: UnknownLocation
- **GIVEN** filepath "misc/random.md" with no recognized pattern
- **WHEN** _calculate_location_weight is called
- **THEN** returns base weight 1.0

### Requirement: ApplyHybridScoring

The system SHALL combine semantic, recency, and location scores

#### Scenario: FullEnhancement
- **GIVEN** result with semantic_score=0.8, recency_score=0.9, location_score=1.5
- **WHEN** enhance is called with weights: semantic=0.7, recency=0.2, location=0.1
- **THEN** calculates enhanced_score = (0.8 * 0.7 + 0.9 * 0.2 + 1.5 * 0.1)
- **AND** returns result with enhanced_score=0.89, semantic_score, recency_score, location_score

#### Scenario: DisabledRanking
- **GIVEN** enable_recency_ranking=false, enable_location_ranking=false
- **WHEN** enhance is called
- **THEN** recency_score=1.0, location_score=1.0
- **AND** enhanced_score equals original semantic_score

#### Scenario: WeightNormalization
- **GIVEN** recency_weight=0.3, location_weight=0.3 (sum=0.6, exceeds 1.0)
- **WHEN** enhance is called
- **THEN** normalizes weights: recency=0.25, location=0.25
- **AND** semantic_weight = 1 - 0.25 - 0.25 = 0.5

### Requirement: SortEnhancedResults

The system SHALL sort results by enhanced score

#### Scenario: MixedResults
- **GIVEN** 3 results with enhanced_scores [0.5, 0.9, 0.7]
- **WHEN** enhance completes
- **THEN** results are sorted to [0.9, 0.7, 0.5] order

## Technical Notes

- **EnhancerConfig**: enable_recency_ranking, enable_location_ranking, recency_weight (0.2), location_weight (0.1), recency_threshold_days (30), min_recency_score (0.2), append_only_recency_factor (0.5)
- **Location weights**: docs=1.5, decisions=1.4, projects=1.3, work=1.2, notes=1.0, memory=1.0, chats=0.8
- **Formula**: enhanced_score = semantic * w_semantic + recency * w_recency + location * w_location
- **Special handling**: Append-only files (memory/YYYY-MM-DD.md) reduce recency weight by 50%
