# API Specification

> Generated by spec-gen v1.0.0 on 2026-02-28

## Purpose

This document specifies the HTTP API exposed by the system.

## Endpoints

### MemoryRetrieval Endpoints

#### Requirement: Classmemoryretrieval

The API SHALL support `class MemoryRetrieval.__init__(config=None)` to initialize memory retrieval system with dependency injection

**Request:**

```json
{
  "config": {
    "type": "ConfigService",
    "required": false,
    "default": null
  }
}
```

**Response:**

```json
{
  "instance": "MemoryRetrieval"
}
```

#### Scenario: DefaultInitialization
- **GIVEN** no config provided
- **WHEN** MemoryRetrieval()
- **THEN** returns MemoryRetrieval instance with default config

#### Scenario: CustomConfigInitialization
- **GIVEN** ConfigService instance with custom data_dir
- **WHEN** MemoryRetrieval(config=custom_config)
- **THEN** returns MemoryRetrieval instance using provided config

### Memory Endpoints

#### Requirement: Instancememory

The API SHALL support `instance MemoryRetrieval.search(query, top_k=5, chunk_mode='chunk')` to search for relevant memory chunks using multi-factor scoring

**Request:**

```json
{
  "query": {
    "type": "string",
    "required": true,
    "maxLength": 1000
  },
  "top_k": {
    "type": "integer",
    "required": false,
    "default": 5
  },
  "chunk_mode": {
    "type": "string",
    "required": false,
    "default": "chunk",
    "enum": [
      "chunk",
      "document",
      "hybrid"
    ]
  }
}
```

**Response:**

```json
{
  "results": [
    {
      "score": "float (0.0-1.0)",
      "filepath": "string",
      "content": "string",
      "source": "string",
      "modified_time": "integer",
      "chunk_id": "string (optional)",
      "chunk_info": "dict (optional)"
    }
  ]
}
```

#### Scenario: BasicSearch
- **GIVEN** memory system initialized with indexed documents
- **WHEN** memory.search('my favorite movies', top_k=3)
- **THEN** returns 3 results sorted by relevance score
- **AND** each result contains score, filepath, content, source, modified_time

#### Scenario: DocumentModeSearch
- **GIVEN** memory system with chunked documents
- **WHEN** memory.search('project notes', chunk_mode='document')
- **THEN** returns full document content instead of chunks

#### Requirement: Functionmemory

The API SHALL support `function save_memory_entry(content, date=None, append=True)` to save a memory entry to the daily file in workspace/memory/

**Request:**

```json
{
  "content": {
    "type": "string",
    "required": true
  },
  "date": {
    "type": "datetime",
    "required": false,
    "default": null
  },
  "append": {
    "type": "boolean",
    "required": false,
    "default": true
  }
}
```

**Response:**

```json
{
  "file_path": "Path to saved memory file"
}
```

#### Scenario: AppendToToday'sMemory
- **GIVEN** current date is 2026-02-27
- **WHEN** save_memory_entry('## Meeting Notes\n- Discussed timeline')
- **THEN** appends content to ~/.openclaw/workspace/memory/2026-02-27.md

#### Scenario: WriteToSpecificDate
- **GIVEN** date object for 2026-02-27
- **WHEN** save_memory_entry('## Retrospective', date=datetime(2026, 2, 27), append=False)
- **THEN** overwrites file for specified date with new content

#### Requirement: Functionmemory

The API SHALL support `function get_memory_file_path(date=None)` to get the path to the daily memory file

**Request:**

```json
{
  "date": {
    "type": "datetime",
    "required": false,
    "default": null
  }
}
```

**Response:**

```json
{
  "path": "Path to memory file"
}
```

#### Scenario: GetToday'sMemoryPath
- **GIVEN** current date is 2026-02-27
- **WHEN** get_memory_file_path()
- **THEN** returns Path('~/.openclaw/workspace/memory/2026-02-27.md')

### Document Endpoints

#### Requirement: Instancedocument

The API SHALL support `instance MemoryRetrieval.add_document(filepath, content=None, chunk_by_sections=True)` to index a single document with validation and security checks

**Request:**

```json
{
  "filepath": {
    "type": "string",
    "required": true
  },
  "content": {
    "type": "string",
    "required": false,
    "default": null
  },
  "chunk_by_sections": {
    "type": "boolean",
    "required": false,
    "default": true
  }
}
```

**Response:**

```json
{
  "success": "boolean"
}
```

#### Scenario: IndexMarkdownFile
- **GIVEN** valid markdown file exists at /path/to/notes.md
- **WHEN** memory.add_document('/path/to/notes.md')
- **THEN** returns True and indexes file with chunking by ## headings

#### Scenario: IndexWithExplicitContent
- **GIVEN** content string provided
- **WHEN** memory.add_document('notes.md', content='## My Notes\nImportant info')
- **THEN** returns True and indexes provided content

#### Scenario: IndexWithoutChunking
- **GIVEN** text file path
- **WHEN** memory.add_document('file.txt', chunk_by_sections=False)
- **THEN** returns True and indexes as single document

#### Requirement: Instancedocument

The API SHALL support `instance MemoryRetrieval.add_documents_batch(files, use_progress=False)` to add multiple documents in batch with progress indication

**Request:**

```json
{
  "files": {
    "type": "array",
    "items": "string",
    "required": true
  },
  "use_progress": {
    "type": "boolean",
    "required": false,
    "default": false
  }
}
```

**Response:**

```json
{
  "results": {
    "type": "object",
    "additionalProperties": "boolean"
  }
}
```

#### Scenario: BatchIndexFiles
- **GIVEN** list of valid file paths
- **WHEN** memory.add_documents_batch(['file1.md', 'file2.txt'], use_progress=True)
- **THEN** returns {'file1.md': true, 'file2.txt': true} with progress logging

#### Requirement: Instancedocument

The API SHALL support `instance MemoryRetrieval.index_directory(directory, recursive=True, base_dir=None)` to recursively index all files in a directory

**Request:**

```json
{
  "directory": {
    "type": "string",
    "required": true
  },
  "recursive": {
    "type": "boolean",
    "required": false,
    "default": true
  },
  "base_dir": {
    "type": "string",
    "required": false,
    "default": null
  }
}
```

**Response:**

```json
{
  "count": "integer"
}
```

#### Scenario: IndexEntireDirectory
- **GIVEN** directory /path/to/notes with markdown files
- **WHEN** memory.index_directory('/path/to/notes')
- **THEN** returns count of indexed files

#### Scenario: IndexWithExclusions
- **GIVEN** config.exclude_dirs set to '.git,__pycache__'
- **WHEN** memory.index_directory('/path/to/project')
- **THEN** returns count excluding git and pycache directories

#### Requirement: Instancedocument

The API SHALL support `instance MemoryRetrieval.index_file(filepath, base_dir=None)` to index a single file and return chunk count

**Request:**

```json
{
  "filepath": {
    "type": "string",
    "required": true
  },
  "base_dir": {
    "type": "string",
    "required": false,
    "default": null
  }
}
```

**Response:**

```json
{
  "chunks": "integer"
}
```

#### Scenario: IndexSingleFile
- **GIVEN** markdown file at /path/to/readme.md
- **WHEN** memory.index_file('/path/to/readme.md')
- **THEN** returns number of chunks
